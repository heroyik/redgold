# 🇨🇳 Mastery(마스터) JSON 생성 규칙 (AI Sidekick)

> ⚠️ **공통 규칙:** `0.rules_common.md` 참조 (`<b>` 태그, JSON 병합, 구어체 생성)

## 🎯 목적
학습 자료에서 핵심 문장을 선별하여 **'Mastery(Golden Sentences)'** 섹션을 생성한다. 앱의 '마스터' 탭에서 렌더링되며, 모든 결과는 `data/lesson{번호}.json`에 저장한다.

## 🛠️ 데이터 구조

모든 Mastery 문장은 **`data/lesson{번호}.json`의 `key_sentences` 배열**에 저장된다.

| 구성 요소 | 설명 |
|-----------|------|
| **Standard Han** | 교재에 있는 원문 그대로의 문장. `<b>` 태그로 핵심 문법 패턴 강조 |
| **Living Language** | 원어민이 실제로 사용하는 생생한 구어체 |
| **Context** | 사용 상황 태그 (예: "칭찬할 때", "거절할 때") |

## ⚙️ 처리 가이드

1. **본문 분석**: 해당 과의 본문(Texts) 대화나 독백을 분석하여 학습 가치가 높은 문장 **4~5개**를 엄선한다. 단순한 문장보다 핵심 문법이나 빈출 표현이 포함된 문장을 우선으로 둔다.
2. **구어체 변환 및 Enrichment**: AI가 독자적으로 자연스러운 구어체 버전과 뉘앙스 설명을 생성한다. 트렌디하고 생생한 어휘를 사용한다.
3. **JSON 업데이트**: `data/lesson{번호}.json` 파일을 열어 `key_sentences` 필드를 찾는다. 기존 데이터가 있다면 최신 내용으로 갱신(Update)하거나 추가(Append)하여 정확성을 유지한다.
4. **Translation pack 업데이트**: `key_sentences`를 추가/수정하면 `translations.keySentences`도 함께 생성/갱신한다.
5. **최종 검증**: JSON 스키마(키 이름, 데이터 타입)가 `lesson1.json`과 완벽히 일치하는지 확인한다. `key_sentences.length === translations.keySentences.length`이며 두 배열의 순서가 일치해야 한다.
