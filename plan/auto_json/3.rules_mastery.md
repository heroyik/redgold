# 🇨🇳 Mastery(마스터) JSON 생성 규칙 (AI Sidekick)

> ⚠️ **공통 규칙:** `0.rules_common.md` 참조 (`<b>` 태그, JSON 병합, 구어체 생성)

## 🎯 목적
학습 자료에서 핵심 문장을 선별하여 **'Mastery(Golden Sentences)'** 섹션을 생성한다. 앱의 '마스터' 탭에서 렌더링되며, 모든 결과는 `data/lesson{번호}.json`에 저장한다.

## 🛠️ 데이터 구조

모든 Mastery 문장은 **`data/lesson{번호}.json`의 `key_sentences` 배열**에 저장된다.

| JSON 필드 | 설명 |
|-----------|------|
| `sentence` | 교재에 있는 원문 그대로의 문장. `<b>` 태그로 핵심 문법 패턴 강조 |
| `pinyin` | `sentence`의 정확한 병음 |
| `translation` | Standard Han의 영어 번역 |
| `colloquial_equivalent` | 원어민이 실제로 사용하는 생생한 구어체 중국어 |
| `colloquial_pinyin` | `colloquial_equivalent`의 정확한 병음 |
| `colloquial_translation` | Living Language의 영어 번역 |
| `context` | 사용 상황 태그. 원본 필드에는 한국어로 저장하고, translation pack에는 `ko`, `ja`, `en`을 모두 저장 |

`translations.keySentences[sentence]`에는 반드시 아래 3개 객체를 생성한다.

```json
{
  "translation": { "ko": "...", "ja": "...", "en": "..." },
  "colloquial_translation": { "ko": "...", "ja": "...", "en": "..." },
  "context": { "ko": "...", "ja": "...", "en": "..." }
}
```

## ⚙️ 처리 가이드

1. **본문 분석**: 해당 과의 본문(Texts) 대화나 독백을 분석하여 학습 가치가 높은 문장 **4~5개**를 엄선한다. 단순한 문장보다 핵심 문법이나 빈출 표현이 포함된 문장을 우선으로 둔다.
2. **구어체 변환 및 Enrichment**: AI가 독자적으로 자연스러운 구어체 버전과 뉘앙스 설명을 생성한다. 트렌디하고 생생한 어휘를 사용한다.
3. **JSON 업데이트**: `data/lesson{번호}.json` 파일을 열어 `key_sentences` 필드를 찾는다. 기존 데이터가 있다면 최신 내용으로 갱신(Update)하거나 추가(Append)하여 정확성을 유지한다.
4. **Base 필드 동시 갱신**: 기존 `key_sentences`에 `translation`만 있고 구어체 필드가 없을 수 있다. 이 경우 반드시 원본 항목 자체에 `colloquial_equivalent`, `colloquial_pinyin`, `colloquial_translation`, `context`를 채운다. translation pack만 채우면 불완전하다.
5. **Translation pack 업데이트**: `key_sentences`를 추가/수정하면 `translations.keySentences`도 함께 생성/갱신한다. key는 `<b>` 태그를 포함한 `sentence` 원문과 정확히 일치해야 한다.
6. **최종 검증**: JSON 스키마(키 이름, 데이터 타입)가 `lesson1.json`과 완벽히 일치하는지 확인한다. `key_sentences.length === Object.keys(translations.keySentences).length`이며 두 집합의 sentence key가 일치해야 한다.

## ✅ Mastery 생성 후 필수 검증

- 모든 `key_sentences[]` 항목에 `sentence`, `pinyin`, `translation`, `colloquial_equivalent`, `colloquial_pinyin`, `colloquial_translation`, `context`가 존재
- `translations.keySentences[sentence]`가 모든 `key_sentences[].sentence`에 대해 존재
- `translations.keySentences[sentence].translation`, `colloquial_translation`, `context`가 각각 `ko`, `ja`, `en`을 모두 포함
- `translations.keySentences`에 원본 `key_sentences`에 없는 extra key가 없어야 함
- Lesson 12/16/17처럼 기존 mastery 문장에 구어체/context 필드가 빠진 경우, Mastery 단계 종료 전에 base 필드와 translation pack을 모두 보완
