# 🇨🇳 Kewen(课文) JSON 생성 규칙 (AI Sidekick)

> ⚠️ **공통 규칙:** `0.rules_common.md` 참조 (병음, `<b>` 태그, JSON 병합, 번역, 코드 참조)

## 🎯 목적
중국어 학습 자료의 **'课文(본문/대화)'** 이미지를 분석하여, `data/lesson{번호}.json`의 `texts` 배열을 프로젝트 표준에 맞춰 생성하거나 업데이트한다.

## 🛠️ 데이터 구조

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | number | 해당 레슨 내 텍스트 순서 (1부터 시작) |
| `title` | string | `{중문} ({영문})` 형식. `"Lesson {N}:"` 접두사 없음, pinyin 없음 (예: `"孙月和王静聊王静的男朋友 (Sun Yue and Wang Jing talk about Wang Jing's boyfriend)"`). 레슨 제목(title)은 `lesson-schema-canonical.md` 참조 |
| `audio` | string | `audio/{lessonId}-{textId}.mp3` 형식 (예: `audio/01-1.mp3`) |
| `content` | array | 화자별 대화 목록 (아래 세부 필드 참조) |
| `proper_nouns` | array | 이름, 지명 등 고유 명사 (`word`, `pinyin`, `meaning`). 본문에 고유명사가 없으면 생략 가능 |
| `vocabulary` | array | 해당 텍스트 하단 핵심 단어 (`word`, `pinyin`, `meaning`) |

본문 생성/수정 시 원본 `texts[].content`만 갱신하지 말고, translation pack의 `translations.texts[text.id].lines[index].translation`도 반드시 함께 생성/갱신한다.
본문/단어장을 새로 생성하거나 보강할 때는 `translations.lessonTitle`, `translations.textTitles`, `translations.vocabulary`, `translations.properNouns`도 함께 생성/갱신한다.

### content 세부 필드
- **`speaker`**: 화자 이름. 독백인 경우 `"独白"`
- **`text`**: 본문 한자. 핵심 문법 패턴은 `<b>` 태그로 강조
- **`pinyin`**: 성조가 포함된 정확한 병음
- **`translation`**: 자연스러운 한국어/영어 번역

## ⚙️ 처리 가이드

1. **이미지 OCR 및 분석**: 텍스트 번호, 제목, 화자, 대화 내용, 하단 단어장을 정확히 분리한다.
2. **병음 생성 표준**: 공통 규칙의 병음 표기 규칙을 따르되, 단어별 띄어쓰기를 반드시 준수한다 (예: `nǐ hǎo` vs `nǐhǎo`). 문장 부호 뒤에는 공백을 둔다.
3. **오디오 동기화**: `TextSection.ts`가 한자 수/병음 길이 기반으로 하이라이트 타이밍을 자동 계산하므로, `text`와 `pinyin`은 누락 없이 정확하게 작성한다.
4. **JSON 업데이트 정책**: 기존 파일을 읽어 해당 `id`를 가진 항목이 있으면 교체(Replace), 없으면 추가(Append). `lessonId`와 `title` 유효성을 상단에서 먼저 확인한다.
5. **translation lines 매칭**: `translations.texts[text.id].lines`의 key는 공통 규칙과 동일하게 0-based index를 사용하며, `content` 배열의 개수와 순서를 그대로 맞춘다.
6. **번역 퀄리티**: 딱딱한 교과서 번역이 아닌, 한국인/영미권 사용자가 상황을 바로 이해할 수 있는 자연스러운 문체로 작성한다. `lesson1.json`의 번역 톤을 참고한다.

## ✅ 본문 생성 후 필수 보강 체크

- `translations.lessonTitle`은 레슨 제목의 `ko`, `ja`, `en` 번역을 모두 포함한다.
- `translations.textTitles[text.id]`는 모든 본문 제목에 대해 생성하며 `ko`, `ja`, `en`을 모두 포함한다.
- `translations.vocabulary[word]`는 전체 `vocabulary[]`의 모든 단어에 대해 생성한다.
- `texts[].proper_nouns`는 고유명사가 없는 본문에서는 생략 가능하다. 다만 배열이 존재하면 모든 고유명사 `word`에 대해 `translations.properNouns[word]`를 생성한다.
- `translations.texts[text.id].lines[index].translation`은 `content[index]`와 0-based 순서가 정확히 일치해야 한다.
- Lesson 18/19처럼 기존 파일에 본문은 있으나 `translations.vocabulary`, `lessonTitle`, `textTitles`가 비어 있는 경우, Kewen 단계 종료 전에 반드시 채운다.
